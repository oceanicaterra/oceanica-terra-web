# Oceanica Terra · web

Web pública de Oceanica Terra (educación marítima en español).

- `index.html`: la página completa (HTML, CSS y JS en un solo archivo).
- `netlify.toml`: Netlify publica la raíz del repositorio sin compilar.

Cada cambio en la rama `main` se publica automáticamente en Netlify.
Los libros en PDF **no** se guardan aquí: se venden y entregan desde Payhip.
