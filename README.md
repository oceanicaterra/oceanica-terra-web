# Oceanica Terra · web

Web pública de Oceanica Terra (educación marítima en español).

- `index.html`: la página completa (HTML, CSS y JS en un solo archivo).
- `netlify.toml`: configuración antigua de Netlify (ya no se usa).
- `CNAME`: dominio de GitHub Pages. `.nojekyll`: publica los archivos tal cual.

Desde el 28/10/2026 la web se publica en **GitHub Pages** desde la rama `main` (gratis, sin créditos), con el dominio de Cloudflare. Netlify ya no sirve la web.

- Rama `datos`: noticias diarias y piezas de redes (la web lee las noticias desde GitHub).
- Rama `web`: trabajo diario en la web, que se fusiona en `main` al terminar cada paso.
Los libros en PDF **no** se guardan aquí: se venden y entregan desde Payhip.
