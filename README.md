# Oceanica Terra · web

Web pública de Oceanica Terra (educación marítima en español).

- `index.html`: la página completa (HTML, CSS y JS en un solo archivo).
- `netlify.toml`: Netlify publica la raíz del repositorio sin compilar.

Cada cambio en la rama `main` se publica en Netlify y gasta 15 créditos (plan gratis: 300 al mes). Por eso `main` solo recibe cambios de la web, como máximo 12 veces en 30 días.

- Rama `datos`: noticias diarias y piezas de redes (no se despliega; la web lee las noticias desde GitHub).
- Rama `web`: trabajo diario en la web, que se fusiona en `main` dos veces por semana.
Los libros en PDF **no** se guardan aquí: se venden y entregan desde Payhip.
