# Rama `datos` (Oceanica Terra)

Datos públicos que cambian a diario y **no** republican la web en Netlify:

- `noticias.json`: noticias del día. La web lo lee desde raw.githubusercontent.com.
- `redes/AAAA-MM-DD/`: piezas de Instagram, Facebook y YouTube (servidas por cdn.jsdelivr.net).
- `redes/_sistema/`: calendario, estado de la tarea diaria, novedades de la web, plantilla y registro de despliegues.

Nada de esta rama se despliega en producción. La web vive en `main`.
